# Contributing

The [full source code](https://github.com/FireDragonGameStudio/com.unity.webrtc.fdgs) for the WebRTC package is available on GitHub. This is also where the development happens.

> [!NOTE]
> The source code contains the native code written C++ and describing the way of building native plugin on [README.md](https://github.com/FireDragonGameStudio/com.unity.webrtc.fdgs/blob/main/Plugin~/README.md).


## Reporting bugs

We use [GitHub Issues](https://github.com/FireDragonGameStudio/com.unity.webrtc.fdgs/issues) to track bugs and feature requests.

## Discussion

To ask questions or discuss this package, please use [GitHub Discussions](https://github.com/FireDragonGameStudio/com.unity.webrtc.fdgs/discussions).
